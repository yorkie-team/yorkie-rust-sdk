# Tasks

The plan and the lessons of each task, one pair of files per task.

## Layout

- In progress: [`active/`](./active/README.md)
- Finished: [`archive/YYYY/MM/`](./archive/README.md), by the month the task
  was created

## Naming

- Plan and checklist: `YYYYMMDD-<slug>-todo.md`
- What was learned on the way: `YYYYMMDD-<slug>-lessons.md`

Both start with a `**Created**: YYYY-MM-DD` line. The todo says what will be
done and why, as a checklist that is ticked as the work lands; the lessons
file records what turned out differently from the plan.

When a task's pull request is ready to merge, move the pair to
`archive/YYYY/MM/` in the same pull request.

The milestone plans written before this layout are under
[`../plans/`](../plans/) and stay there.
